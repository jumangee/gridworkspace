## Соглашения документов

Уровни доверия утверждений:

- **[ПРОВЕРЕНО]** — проверено на этой машине: рефлексией по сборкам игры, компиляцией или
  чтением файлов игры. Рядом указано чем.
- **[ИСТОЧНИК]** — найдено в документации или коде сообщества, ссылка рядом.
- **[НЕ ПРОВЕРЕНО]** — гипотеза. Нельзя строить план, пока не проверено.

Если документ противоречит коду — прав код, а документ надо исправить. Если документ
противоречит реальности игры — прав документ, а код надо исправить, и это дефект.
