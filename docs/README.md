# Документация проекта Grid Workspace

Редактор связей блоков грида Space Engineers — как игровой мод на C#.

Полное название проекта — **Grid Workspace**, по-русски — **Центр Управления Гридом** (ЦУГ);
**VGS** — рабочее и историческое имя того же проекта. Оно осталось в путях, префиксе лога
`[VGS]` и в старых документах, поэтому старые имена в ADR и ресёрче не переписаны, а
резолвятся таблицей в [`AGENTS.md`](../AGENTS.md) §«Название проекта»
([ADR-0034](adr/0034-naming-grid-workspace.md)). В новом тексте пишем новое имя.

## Соглашения документов

Уровни доверия утверждений:

- **[ПРОВЕРЕНО]** — проверено на этой машине: рефлексией по сборкам игры, компиляцией или
  чтением файлов игры. Рядом указано чем.
- **[ИСТОЧНИК]** — найдено в документации или коде сообщества, ссылка рядом.
- **[НЕ ПРОВЕРЕНО]** — гипотеза. Нельзя строить план, пока не проверено.

Если документ противоречит коду — прав код, а документ надо исправить. Если документ
противоречит реальности игры — прав документ, а код надо исправить, и это дефект.
