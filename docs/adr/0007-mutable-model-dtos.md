# 0007. `Vgs.Model` — изменяемые носители данных

- Status: accepted
- Date: 2026-11-19
- Supersedes: —
- Joint review: CR-1 (по итогам первого ревью кода)

## Context

Статическое правило R009 (`tools/review-check.ps1`) отметило публичные изменяемые поля в
`Vgs.Model`: `Node.DisplayName`, `Node.Position`, `Node.HasTerminal`, `Node.Subtitle`.

Позиции сторон:

- **Ревьюер:** публичное изменяемое поле на общем типе — это запись, которую нельзя найти
  поиском по имени метода, и место, где легко нарушить инвариант.
- **Программист:** `Node.Position` переписывается обработчиком перетаскивания на каждом
  движении мыши. Превращение в свойство с проверками или в неизменяемый тип с копированием
  даст аллокации в кадровом пути ради защиты инварианта, которого нет.
- **Архитектор:** `Vgs.Model` — снимок состояния для отрисовки, а не доменная модель с
  бизнес-правилами. Инварианты, которые нужно защищать, живут в `GridGraph`
  (связи, удаление узла), и они уже защищены методами.

## Decision

`Vgs.Model` состоит из **изменяемых носителей данных**, и это осознанно:

- поля, которые никогда не меняются после создания, — `readonly`
  (`Node.EntityId`, `Node.SubtypeId`, `Node.GridPosition`, все поля `Edge`, все поля `Port`,
  `GridGraph.GridEntityId`);
- поля, которые действительно меняются (`DisplayName`, `Position`, `HasTerminal`,
  `Subtitle`), остаются публируемыми полями и **обязаны** нести подавление
  `// review:allow R009 <причина>` с указанием, кто и когда их пишет;
- инварианты графа (нет дубликата ячейки, нет ребра на несуществующий порт, удаление
  узла удаляет его рёбра) живут в методах `GridGraph` и проверяются только там. Петля на
  себя — не инвариант: она разрешена ([ADR-0036](0036-self-connection.md)).

Тип, у которого есть инварианты между полями, в этом слое появляться не должен: ему нужен
метод, а метод — это уже `GridGraph`.

## Alternatives

| Вариант | Почему отклонён |
|---|---|
| Все поля — свойства с приватным сеттером | Ограничивает запись без выигрыша: пишет всё равно один вызывающий, и он виден в подавлении |
| `Node` как `struct` | Копирование при передаче в списки и словари; мутация через свойство-геттер молча терялась бы |
| `Node` неизменяемый, изменения через `With` | Аллокация на каждое движение мыши |
| Отключить R009 | Потеряли бы сигнал о новых публичных изменяемых полях в других слоях |

## Consequences

- Легко: ноль аллокаций в пути перетаскивания; модель остаётся простой для чтения.
- Трудно: новый mutable-поле в `Model` требует явного подавления с причиной — это
  намеренное трение.
- Запрещено: добавлять в `Vgs.Model` тип с межпольными инвариантами без методов их защиты.

## Verification

```powershell
pwsh -File tools/review-check.ps1 -Rules R009
```

Должно остаться 0 находок: каждое изменяемое поле либо стало `readonly`, либо несёт
подавление с причиной. Подавление без причины даёт находку R000.
