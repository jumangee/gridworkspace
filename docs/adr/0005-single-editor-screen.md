# 0005. Один экземпляр экрана редактора

- Status: accepted
- Date: 2026-11-18
- Supersedes: —
- Amended by: [0045](0045-hotkey-opens-editor-from-cockpit.md) — у указателя `_openEditor`
  появился **второй читатель**: клавиша **M** спрашивает `VgsEditorScreen.IsEditorOpen`
  (не «`IsOpened`», а `IsOpen` — тот член, который есть у `MyModScreen`) и по нему решает,
  открывать ли экран. Правило «один экран» от этого не меняется, но теперь оно проверяется
  в двух местах, а не в одном.

## Context

Кнопка «Grid setup» есть у каждого кокпита, и нажать её можно повторно, не закрыв
редактор.

Нужно понять, открыт ли редактор уже. Проверено: `MyScreenManager` предоставляет только
`GetGuiScreensForDebug()` — строковый дамп стека экранов для отладочного меню, а не
коллекцию объектов. Поддерживаемого способа спросить «есть ли открытый экран типа X» нет.

## Decision

Держим статический указатель `_openEditor` на текущий экземпляр.

- `OpenFor` при живом `_openEditor` не создаёт второй экран, а поднимает существующий
  наверх (`RaiseToTop`).
- `UnloadData` сбрасывает указатель, если он указывает на этот экземпляр.

Один экран на мод — осознанное ограничение: два редактора разных гридов одновременно
потребовали бы разделения состояния камеры и ввода между экземплярами, что на этапе 1
не даёт ничего.

## Alternatives

| Вариант | Почему отклонён |
|---|---|
| Поиск по `GetGuiScreensForDebug()` | Возвращает строки, не экраны; парсинг отладочного вывода — хрупкая зависимость |
| Разрешить несколько экранов | Дублирование состояния, неопределённый порядок ввода, лишняя сложность без пользы на этапе 1 |
| Флаг в `VgsSession` | Указатель на экран нужен всё равно (чтобы поднять его), так что отдельный флаг был бы вторым источником правды |

## Consequences

- Легко: повторное нажатие не плодит экраны.
- Трудно: если экран уничтожен в обход `UnloadData`, указатель станет висячим — поэтому
  `OpenFor` дополнительно проверяет `IsOpen` (член `MyModScreen`; в первой редакции ADR здесь
  было написано `IsOpened`, и это исправлено вместе с ADR-0045).
  Имя `IsOpened` существует, но у **другого** типа — запрещённого моду
  `Sandbox.Graphics.GUI.MyGuiScreenBase` ([api-surface.md](../01-research/api-surface.md)
  §`Sandbox.Graphics.GUI.MyGuiScreenBase`); оттуда оно и попало в текст. У
  `Sandbox.ModAPI.MyModScreen` член называется `IsOpen`
  ([api-modscreen.md](../01-research/api-modscreen.md) §`Sandbox.ModAPI.MyModScreen`).
- Запрещено: создавать `VgsEditorScreen` в обход `OpenFor`.

## Verification

Открыть редактор → закрыть → открыть снова; затем открыть и, не закрывая, нажать кнопку
ещё раз. Должен быть ровно один экран. Регрессия R-003.
