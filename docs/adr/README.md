# Архитектурные решения (ADR)

Каждое решение, которое дорого откатывать, записано здесь. ADR — это не отчёт: это
контракт. Код, противоречащий принятому ADR, считается дефектом, пока ADR не заменён
новым.

## Статусы

| Статус | Значение |
|---|---|
| `proposed` | предложено, ещё не действует |
| `accepted` | действует; код обязан соответствовать |
| `superseded by NNNN` | заменено более новым решением |
| `rejected` | рассмотрено и отклонено; причина в тексте |

## Как добавить

1. Скопируйте [`_template.md`](_template.md) в `NNNN-<краткая-тема>.md` (следующий номер).
2. Заполните `Context`, `Decision`, `Consequences`, `Verification`.
3. Если решение меняет прежнее — укажите `Supersedes:` и переведите старый ADR в
   `superseded by NNNN`.
4. Добавьте строку в таблицу выше.

Решение, принятое в совместном ревью, обязательно ссылается на CR:
[`docs/review/joint-review.md`](../review/joint-review.md).
