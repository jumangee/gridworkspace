# 0003. Слои и правило «Ui не читает мир при рисовании»

- Status: accepted
- Date: 2026-11-18
- Supersedes: —

## Context

Мод живёт внутри игрового цикла. `Draw()` вызывается каждый кадр, `UpdateAfterSimulation`
— каждый тик. Обращение к живому блоку (`IMyTerminalBlock`) — это поиск в мире, который
дороже любой арифметики, и он может упасть, если блок уничтожен между кадрами.

Кроме того, запуск игры — самая дорогая операция в цикле разработки. Всё, что можно
проверить без неё, должно быть проверяемо без неё.

## Decision

Четыре слоя с односторонними зависимостями:

```
Vgs.Core  →  ничего игрового, кроме чтения фасада сессии
Vgs.Model →  НЕ ссылается на Sandbox.*, VRage.Game.ModAPI, VRage.ModAPI
Vgs.Game  →  единственное место, где читаются и пишутся живые сущности
Vgs.Ui    →  читает только снимок модели; никогда не читает мир при рисовании
```

Разрешённые зависимости: `Ui → Model`, `Ui → Game` (только для вызова обновления),
`Game → Model`, `Game → Core`, `Ui → Core`, `Model → (ничего)`, `Core → (ничего)`.

`VRageMath` разрешён в `Model`: это библиотека значимых типов (`Vector2`, `Vector3I`) без
доступа к сущностям. Переписывать векторы ради формальной чистоты было бы хуже.

Правило для `Ui`: данные для отрисовки приходят из `GridGraph`, обновляемого по таймеру
(`RefreshIntervalFrames`), а не из игры на каждом кадре. Строки, отображающие редко
меняющиеся значения, кэшируются и пересобираются при изменении значения.

## Alternatives

| Вариант | Почему отклонён |
|---|---|
| Один слой, обращение к блокам по месту | Невозможно проверить логику без игры; просадки кадров на больших гридах |
| Отдельный поток для чтения грида | Игровые API не потокобезопасны; маршалинг сложнее выигрыша |
| Кэш в `Vgs.Ui` вместо модели | Дублирование состояния и рассинхронизация с моделью |

## Consequences

- Легко: `Vgs.Model` тестируется и ревьюится без запуска игры; отрисовка предсказуема по
  стоимости.
- Трудно: на границе `Game → Model` нужны конвертеры; новые данные для UI требуют
  протаскивания через снимок.
- Запрещено: `using Sandbox.*` и `using VRage.Game.ModAPI` в `Model`; чтение
  `IMyTerminalBlock`/`IMyCubeGrid` из методов `Draw*`.
- При ошибке страдает один слой.

## Verification

```powershell
pwsh -File tools/review-check.ps1 -Rules R001,R010
```

`R001` ловит игровые `using` в `Model`, `R010` — аллокации и LINQ в методах `Draw*`.
Оба должны давать 0 находок.
