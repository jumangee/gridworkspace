# Icons that go into the atlas, one per line.
#
#   <id>  <svg file>  <comment for the generated doc comment>
#
# The id becomes a member of the generated `VgsIcon` enum, so it must be a valid C# identifier.
# Order is the atlas cell order and the enum order; appending a line is the normal case.
#
# After editing: pwsh -File tools/build-icon-atlas.ps1
#
# Every line added here must also get a row in docs/07-icon-catalog.md: the catalogue is what
# tells a reader which control draws which icon, and tools/check-icon-catalog.ps1 fails when the
# two lists disagree.

SquarePlus      square-plus-regular.svg   square-plus (Regular): the bind button of a one-group toolbar
Xmark           xmark-solid.svg           xmark (Solid): the remove-connection glyph
Bell            bell-regular.svg          bell (Regular): the watch-list button of an event controller
LightbulbSolid  lightbulb-solid.svg       lightbulb (Solid): the bind button of the "true" group
LightbulbRegular lightbulb-regular.svg    lightbulb (Regular): the bind button of the "false" group
ShareFromSquare share-from-square-regular.svg share-from-square (Regular): the jump-to-terminal button of a block card
Sliders         sliders-solid.svg          sliders (Solid): the modes button of the bottom bar
ToggleOn        toggle-on-solid.svg        toggle-on (Solid): the card's block-power switch while the block is on
ToggleOff       toggle-off-solid.svg       toggle-off (Solid): the card's block-power switch while the block is off or too damaged to be switched on
